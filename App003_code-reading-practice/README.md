# コードリーディング練習 (code-reading-practice)

ソースコードを読んで「何をしているか」を自分の言葉で説明する練習をするための Web アプリです。
書く練習に比べて機会が少ない「読む力」を、短いコードの反復で鍛えることを目的に、自分の学習用として開発しました。

## 概要

ソースコードを読んで説明する練習用の Web アプリです。問題のコードを読み、その動作を自分の言葉で説明し、模範解説や AI の添削で答え合わせをします。

## 使い方

### 開き方

下の URL をブラウザで開くだけで使えます。インストールやアカウント登録は不要です。

### 基本の流れ（AI なしで使えます）

1. ホーム画面で練習したい言語（Python / C言語 / JavaScript）を選びます。
2. 「レベル別」（Lv1〜Lv5）か「文法テーマ別」（if文）からカテゴリを選びます。
3. 問題一覧から問題を選びます。まだ解いていない問題が上に並びます。
4. コードを読み、「このコードは何をしていると思いますか?」の欄に自分の言葉で説明を書きます。
   この欄は練習用なので保存されません（ページを離れると消えます）。
5. 「答えを見る」を押して、模範解説と見比べます。
6. 「理解できた」か「まだ不安」を押して自己評価します。一覧に「理解済み」「要復習」と表示され、並び順にも反映されます。

### AI に添削してもらう（任意）

ChatGPT・Gemini・Claude など、普段使っている AI チャット（無料版で OK）を使います。API キーや追加の登録は不要です。

1. **最初に1回だけ**：ホーム画面の一番下「AIを使う準備（最初に1回だけ）」の文章をコピーし、AI チャットの新しい会話に貼って送信します。
2. 問題ページで説明を書いたあと、「AIに添削してもらう（クリックでコピー）」を押します。AI に送る文章が自動でコピーされます。
3. 手順1の会話の続きに貼り付けて送信します。
4. AI から返ってきた回答（`{` で始まる JSON）を丸ごとコピーし、アプリの「AIからの回答を貼り付け」欄に貼って「反映する」を押します（Enter キーでも反映できます）。
5. 判定（正解 / おおむね正解 / 要復習）とフィードバックが保存されます。「保存したフィードバックを見る」で確認できます。あわせて「答えを見る」の模範解説も、具体的な実行結果が分かる形に更新されます。

反映時にエラーが出た場合は、AI の回答の一部だけをコピーしていないか確認してください。

### AI で新しい問題を作る（任意）

問題一覧の「AIで新しい問題を生成する（クリックでコピー）」を押し、上と同じ手順（AI に貼る → 回答を貼り戻して「反映する」）で、そのカテゴリに問題が追加されます。

### 自分のコードを問題にする

1. ホーム画面の「＋ 自分のソースコードを登録する」を押します。
2. 「ソースコード」欄にコードを貼り付けます。言語は自動で判定されます（違っていたら選び直せます）。
3. 「登録する」を押すと、その言語のページの「自分のコード」から練習できます。
   解説を書かなくても、AI に添削してもらうと解説が自動で作られます。

### 自分用メモ

問題ページ下部の「自分用メモ（保存されます）」の「表示する」を押すと、気づいたことを書き残せます。こちらは保存されます。

### データの保存と引き継ぎ

- 学習データ（自己評価・AI フィードバック・メモ・追加した問題）は、使っているブラウザの中に自動で保存されます。
- ブラウザの閲覧データを削除すると消えます。また、シークレットウィンドウでは保存されません。
- 別のブラウザや端末に移したいときは、ホーム画面の「データのバックアップ・引き継ぎ」で「エクスポート」の内容をコピーし、移行先で同じ画面を開いて「インポート」欄に貼り付け、「取り込む」を押してからページを再読み込みしてください。

## 主な機能

- **言語・レベル・文法トピック別の問題**
  Python / C / JavaScript の3言語。Lv1（変数・出力）〜 Lv5（応用）のレベル別と、「if文」などの文法トピック別に問題を選べます。
- **説明 → 答え合わせ → 自己評価の学習サイクル**
  コードを読んで説明を書き、模範解説（具体的な出力結果まで明記）で答え合わせし、「理解できた / まだ不安」で自己評価します。
- **自分の AI と連携した添削・問題生成（API キー不要）**
  アプリがプロンプトを組み立ててワンクリックでコピー → ChatGPT / Gemini / Claude など普段使っている AI に貼り付け → 返ってきた JSON をアプリに貼り戻す、というコピペ連携方式です。
  - 自分の説明の添削（判定 + フィードバック）と、模範解説の強化・生成を1回のやり取りで実行
  - 指定したレベル・トピックに合わせた新しい問題の生成
- **自分のコードのストック**
  手元のコードを貼り付けると言語を自動判定し、練習問題として保存できます。
- **復習しやすい一覧表示**
  未挑戦 → 要復習 → 理解済み の順に並び、前回の AI 判定バッジや解答日時を一覧で確認できます。
- **データのバックアップ・引き継ぎ**
  学習データを JSON でエクスポート / インポートでき、別の URL や端末へ移行できます。

## 設計上の工夫

- **有料 API を使わない AI 連携**
  サーバーや API キーを持たずに AI の恩恵を受けられるよう、コピペ連携にしました。AI の出力は JSON 形式を指示したうえで、コードフェンスの除去や文字列内の生の改行のエスケープなど、崩れた JSON にも耐えるパース処理を入れています。
- **カンニングにならない UI**
  模範解説・保存した AI フィードバック・自分用メモはどれも初期状態で非表示にし、クリックで開く形にしています。また「自分の言葉で説明」欄は、毎回白紙から説明する練習になるよう意図的に保存しません。
- **サーバー不要・静的ホスティング対応**
  データはすべてブラウザの localStorage に保存し、HashRouter と相対パスのビルド設定により、静的ファイルを置くだけで動作します。

## 手元で動かす（開発者向け）

普通に使うだけなら不要です。ソースコードを変更して動かしたい場合の手順です。Node.js 20 以降が必要です。

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

その他のコマンド:

```bash
npm run build    # 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果の確認
npm run lint     # oxlint による静的解析
```

## ディレクトリ構成

```
src/
├── components/  # コードブロック表示、AI コピペ連携パネルなどの共通部品
├── data/        # 組み込みの問題データ
├── hooks/       # 進捗・フィードバック・メモなどの localStorage 永続化
├── lib/         # AI 用プロンプト生成、AI 応答のパース、言語自動判定
└── pages/       # 各画面
```

## 補足

学習データはブラウザの localStorage に保存されるため、ブラウザや URL が変わる場合は「データのバックアップ・引き継ぎ」画面から移行してください。
