# App002_time-bomb

## 概要
時限爆弾風のカウントダウンタイマーです。
日付と時刻を指定すると、その時刻までの残り時間を「時:分:秒:1/100秒」で表示し、0になると画面が赤く点滅します。

## 使い方

### 開き方
下の URL をブラウザで開くだけで使えます。インストールは不要で、スマートフォンでも使えます。

**https://mk07212243.github.io/mk_my-portfolio/App002_time-bomb/**

インターネットにつながっていない環境で使いたい場合は、このフォルダの `countdown-timer.html` を開き、右上の「Download raw file」ボタンでダウンロードして、ダブルクリックでブラウザで開いてください。

### 操作
1. **DATE** に、カウントダウンの終わりの日付を指定します（最初は今日の日付が入っています）。
2. **TIME** に、終わりの時刻を「時:分:秒」で指定します。
3. **START** を押すと、画面上部が「COUNTING DOWN」に変わり、残り時間が「時:分:秒:1/100秒」で減っていきます。
4. 残り時間が0になると「TIME UP」と表示され、画面が赤く点滅します。
5. **RESET** を押すと、カウントダウン中・終了後のどちらでも最初の設定画面に戻ります。

※ 過去の日時を指定して START を押すと、すぐに「TIME UP」になります。
